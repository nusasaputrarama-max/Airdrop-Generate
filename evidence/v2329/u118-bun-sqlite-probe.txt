--- conclusion ---
- Database exposes only `filename` (the path string as given) and
  PRAGMA database_list returns the path string only. Neither is an
  inode/device identity.
- No fd property exists ($handle/fd/_fd all absent). `db.handle` is a
  bare number (0 on a fresh DB) with no identity meaning.
  `fileControl()` returns no file identity (opcodes 30/31/32 all
  return the same bare number 12).
- A post-open statSync(path) would only re-read the PATH, not the
  opened file, so it cannot prove the opened inode equals the guarded
  inode. The guard->open TOCTOU therefore CANNOT be closed from
  inside the process with Bun's API.
- Enforceable boundary instead: operator-configured allowlisted
  working directory (env PRINCIPAL_MIGRATION_ALLOWED_DIR, enforced
  in guardDbPath(); explicit U-118 WARNING on every run when unset).
  Residual U-118 stays OPEN.
