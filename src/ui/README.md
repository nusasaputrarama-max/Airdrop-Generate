# UI — AIRDROP GENERATE (AG-001)

Komponen UI target (Next.js + Tailwind CSS + shadcn/ui). Belum ada komponen yang
diimplementasikan di paket ini — UI yang live saat ini berada di artifact
`cek-link-airdrop` dan tetap menjadi UI produksi sampai cutover (M5).

Brand: background gelap `#0B0E11`, aksen emas `#F0B90B`, teks putih `#F5F5F5`.
Bahasa: Bahasa Indonesia penuh.

Komponen yang direncanakan (shadcn/ui sebagai basis):

- `Navbar` — logo (ikon emas + wordmark), navigasi, tombol Hubungkan Wallet
- `Hero` — headline, subheadline, pencarian, pill "Dibangun oleh anak bangsa Indonesia"
- `ProjectCard` / `ProjectDetail` — kartu + modal detail proyek
- `ScanForm` / `ScanResult` — form tempel link + hasil vonis + bukti per sinyal
- `GibranChat` — tombol melayang + jendela chat asisten Gibran
- `Dashboard` — bookmark + status tugas
- `Guide` / `About` — panduan keamanan + misi + kredit pembuat
